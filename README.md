# Portfolio Personnel

Ce repository contient le code source de mon portfolio professionnel, réalisé en HTML et CSS.

Il présente :
- Mes projets web avec des captures(à venir) et descriptions
- Mes compétences en développement front-end
- Liens de contact pour me joindre

💡 Objectif : fournir un site clair, responsive et esthétique pour montrer mon travail de développeur web.

Technologies utilisées : HTML5, CSS3, animation JS,  design responsive, bonnes pratiques SEO.

Le portfolio est conçu pour être facilement maintenable et extensible.
